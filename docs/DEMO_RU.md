# ClearTalk - показ двух наложенных голосов

Проверка и обновление: 10 ноября 2026 года.

## Запуск на этом Mac

1. Открой папку `cleartalk` внутри `Desktop/nlp/nlp-project`.
2. Двойной щелчок по `Start ClearTalk.command`. Оставь Terminal открытым.
3. Открой адрес, который напечатает launcher, обычно http://127.0.0.1:8765.
4. Выбери Conversation / Разговор, затем Speakers / Говорящие: `2 · at the same time` / `2 · одновременно`.
5. Нажми карточку «Казахский + русский: два голоса одновременно», затем кнопку распознавания. Язык и распознаватель оставь Auto.
6. Прослушай исходник, затем отдельные дорожки Speaker 1 и Speaker 2. Сравни их тексты и временные интервалы.

Можно загрузить свой WAV/MP3/M4A вместо примера. Для этого режима лимит 30 секунд, ровно два голоса. Для длинных записей с очередностью речи используй обычный Conversation. Не загружай разговоры без согласия участников.

Первый проверенный прогон: 9,72 секунды аудио, 40,39 секунды обработки на CPU. Это наблюдение одного запуска, не обещание скорости. Казахская фраза распознана как в эталоне примера; русская содержит ошибки («используются»/«используется», «жаркого»/«Жаркова»).

Исходный пример: `samples/two_voices_kk_ru_en/kazakh_and_russian.wav`; тексты и происхождение в соседних `manifest.json` и `README.md`. Это составленные фразы FLEURS с 4,8 секунды наложения, а не настоящая встреча. Эталонные тексты не подставляются в ответ модели.

## Что обновлено

- Многоязычный режим отдаёт две реальные WAV-дорожки и текст каждой, а не только общую таблицу реплик.
- Метки дорожек соответствуют текстам. Они не означают распознавание личности.
- Если два разных текста получить не удалось, приложение честно сообщает о возврате к исходнику.
- Добавлены проверки формы и конечности аудиосигнала, границ интервалов и сохранения дорожек.
- Кнопка демо в режиме двух одновременных голосов теперь выбирает короткий русско-казахский пример, а не длинную запись с шестью читающими по очереди.

## Модели и метрики для питча

Установленные веса совпадают по SHA-256 со всеми 33 файлами приложенного пакета моделей. ZIP с `(1)` содержит тот же список файлов, размеры и CRC, что пакет без суффикса. Новый файл не означает новое обучение. Для казахского и русского оставлен ClearTalk large, выбранный ранее на validation; английский маршрут использует turbo. Обучение и подбор по финальному тесту в этом обновлении не выполнялись.

Сохранённые результаты предыдущих экспериментов (не новый пересчёт): mixed-language test B - 9,7% WER у ClearTalk large против 30,0% у исходной казахской модели; английские наложенные голоса - 20,74% против 26,16%. Подробности и ограничения в `DETAILS.md`. Смешение языков по очереди не равно одновременному наложению русской и казахской речи: эти показатели нельзя приписывать сегодняшнему демо.

WER = (замены + удаления + вставки) / число слов эталона. CER считает ошибки символов. Меньше лучше. Не называй `100 - WER` accuracy. Для разделения полезен SI-SDR, для распределения слов по говорящим - cpWER и отдельно ошибки атрибуции. Новые показатели требуют человеческих эталонов и отдельного заранее зафиксированного набора; после просмотра его ошибок нельзя выбирать на нём модель.

Короткая формулировка: «ClearTalk помогает разобрать запись, когда люди перебивают друг друга. Мы выделяем две дорожки и показываем речь каждого на русском и казахском. Распознаватель адаптирован с LoRA. Демонстрация работает локально; качество реальных встреч ещё предстоит измерить».

## Что дальше

1. До питча записать с согласия участников 3-5 коротких живых примеров для демонстрации, вручную проверить тексты и сохранить резервную запись экрана. Не использовать их как независимый тест после настройки на них.
2. Отдельно согласовать новый RU/KK benchmark с невиданными говорящими, эталонами двух голосов и baseline. Новое обучение требует отдельного согласования данных и проверки.
3. Исходники, инструкции и результаты опубликованы в [al1naaa/clear_talk](https://github.com/al1naaa/clear_talk). Пользовательские записи, личные заметки, токены, среды и многогигабайтные веса исключены. Папка для GitHub находится в `Documents/ChatGPT/nlp/clear_talk-public`; установленное приложение остаётся на рабочем столе.

Для русского и казахского используется режим Conversation с выбором «2 · одновременно».
Обычный Separate + transcribe пока использует английский распознаватель.

Говорящий 1/2 - условные метки внутри записи, не установленные личности.
Демонстрация не является измерением точности на независимом тестовом наборе.
